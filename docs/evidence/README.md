# Evidence archive

Start with the repository's [Evidence Index](../../README.md#evidence-index) for the strongest DAW-1 through DAW-6 witnesses and the [DAW-6 sign-off](../daw-6.md) for the full gate and limitations.

**Publication notice:** files listed in the [redaction manifest](../publication/redaction-manifest.json) are path-redacted public presentations of locally preserved originals. Test outcomes and source fingerprints are unchanged. Historical artifact hashes still refer to the originals, not the redacted public bytes. Read the [hash and provenance rules](../publication/README.md) before verifying them. This applies to all nested milestone and diagnostic directories.

This archive includes successful gates and explicitly failed diagnostic/mutation runs. Expected mutation failures demonstrate regression detection; other failed attempts are not counted as successful validation. No throughput/SLO, production deployment or live LLM evidence is implied.
